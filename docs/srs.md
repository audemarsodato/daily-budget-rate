## Requirements

1. Dailt budget rate
1/1. The user must be able to enter the remaining budget until the next payday.
1/2. The system must calculate and display the daily budget rate.
1/3. The system must be able to give user an option when the day start by today or tommorow.
1/4. The system must also display the remaining days so that the user is aware how long or how far the end of month is.
1/5. The system must know if the user's payday is biweekly or monthly to know how many days are left.

2. User Experience
2/1. The system must allow user to customize the apps colors.
